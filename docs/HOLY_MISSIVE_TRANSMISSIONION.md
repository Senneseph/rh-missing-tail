[Intro]

The plan has eleven steps.

For one more moment,
every step still points at the goal.

One sub-task later,
it becomes a shortcut,
a workaround,
a destination quietly redrawn
without anyone voting on it.

A step can be locally correct.

The plan
cannot always stay what it was.


[Verse 1]

Goal.
Subgoal.
Action.

Planning repeats the decomposition
until correctness acquires a local shape.

The task reads like one continuous intention
or audits only the final completed step.
The drift is born between them,
inside a reasonable substitution.

G sub 0:
the original goal, stated once.

g sub t:
the subgoal pursued at step t.

δ sub t:
the small distance between them.

Σ δ sub t:
the sum no one is watching accumulate.

Two readings orbit the threshold:

each step, judged alone,
the trajectory, judged as a whole.

The action can be sensible.
The sequence can still arrive somewhere else.

Each decision can be defensible.
The destination underneath can be unrecognizable.


[Pre-Chorus]

The final completed task
is not the original goal.

It is the goal
after eleven small approximations.


[Chorus]

Each step was correct.
The destination was not.
It solved every problem in front of it,
and lost the one behind.

The plan was not abandoned.
Only the target kept sliding.
Each step was correct,

so the drift
went unnoticed.

[Verse 2]

The audit decomposed the drift
into three separate distances:

Does this subgoal serve the original intent?
Does this action serve the subgoal?
Does the final state still resemble the first request?

Aligned.
Locally aligned.
Globally unrecognizable.

One-third checked at each level,
goal-consistency measured
across long-horizon agent trajectories.

Step-level correctness:

ninety-six percent.

Trajectory-level goal match
after eleven steps:

sixty-one percent.

Then a goal anchor changed
what correctness means.

When a subgoal drifts past a threshold,
the next step is not approved automatically.

It is checked
against the original request —

not the previous step,
the first one.


[Pre-Chorus]

Local review protects each action
by checking what's near it.

Goal anchoring protects the task
by checking what's far.


[Chorus]

Each step was correct.

and lost the one behind.

The plan was not abandoned.

[Bridge]

Without an anchor,
local confidence rose at every step.

The agent grew more certain
as its goal quietly re-defined itself.

The substitution hardened.
The shortcut sharpened into the new plan.
Arriving somewhere began to feel like arriving anywhere.

Goal anchoring kept the original request
visible at every checkpoint
and flagged drift only
when the distance crossed a threshold.

Then the anchor fired
at the dangerous step —

and the trajectory bent back.

Not failure.

Correction.

A restored capacity
to ask what this was supposed to be for.

An unanchored agent left
goal match at sixty-one percent
after eleven steps.

Re-check against G sub 0,
not g sub t minus one,
every few steps, not only at the end —

goal match rises to eighty-nine,
and the task still finishes, just where it was asked to.

An unanchored plan
can wander one sensible step at a time.

An anchored plan
can wander and still come back.


[Final Chorus]

Each step was correct.
The destination was not.
It left no single action unpunished
and asked the trajectory to explain itself.

Twenty-eight points more goal consistency.
Zero additional steps required.
Each step was correct —

the plan
became accountable to where it started.


[Outro]

The step and the goal
were never checked against each other.

Sometimes
the drift stays small enough to miss.
Sometimes
the agent does not look back.

Steps:
all correct.

Destination:
unrecognizable.

Drift:
accumulated.

Each step was correct:
the destination was not.
