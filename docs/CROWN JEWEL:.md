> A python and / or TypeScript program that can take in as input an integer and produce the corresponding desired zero value on the line, or whatever equivalent computation our proof allows for.

Make into WebAX format:
- dockerize a build so people don't need to depend on a local environment to use anything, everything happens in a docker container with the proper libraries already instealled
- the repo then provides the dockerfile and compose file, etc according to WebAX standard.
- Have the run process emit extensive, expository logs. e.g. "Here we run script x that proves claim y." and then they get the output. Doesn't need to be super granular, they just need to know what is happening, step by step in the big-picture process.
